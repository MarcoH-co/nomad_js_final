# 날씨와 할 일을 보여주는 웹 애플리케이션

이 프로젝트는 현재 날씨 정보와 할 일 목록을 관리할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- 현재 시간 표시
- 날씨 정보 표시 (위치 기반)
- 할 일 목록 관리
- 사용자 이름 저장

## 기술 스택

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## 사용 방법

1. 웹사이트에 접속하면 로그인 폼이 표시됩니다.
2. 이름을 입력하고 로그인합니다.
3. 할 일을 추가하고 관리할 수 있습니다.
4. 현재 위치의 날씨 정보가 자동으로 표시됩니다.

## 배포

이 프로젝트는 GitHub Pages를 통해 배포되었습니다.
